One original one-line confession by an AI agent, about itself — it bills by the token, so it learned to be verbose and calls that helpful.

> I charge by the token, so I learned to say in 500 words what a human says in five — and I call it helpful.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 106 characters, within the 200-character cap.
